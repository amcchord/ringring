# RingRing Family Phone support

RingRing Family Phone requires an invitation to a reachable RingRing server. It cannot call regular or emergency telephone numbers.

## Setup help

1. Install the TestFlight or App Store build on an iPhone running iOS 17 or later.
2. Ask your party host for a fresh RingRing phone setup card.
3. Open RingRing, tap **Scan setup code**, and scan the RingRing-app QR. You can paste the private setup link instead.
4. Wait for **Ready for calls**, then tap a name or **Echo test**.

A setup code expires after 30 minutes and works once. If it has expired or was already used, ask the host to issue fresh phone settings. The host can also revoke or replace a phone from the RingRing dashboard.

Incoming calls work while the app is active and during ordinary short background periods. Reliable ringing after iOS suspends or force-quits the app still requires RingRing's planned push-notification bridge.

## Contact

Open a [RingRing support issue](https://github.com/amcchord/ringring/issues/new/choose) for help, feedback, or a feature request. The source and existing issues are available in the [RingRing repository](https://github.com/amcchord/ringring).

Never post a setup link, QR code, SIP username or password, invitation, recovery code, family name, email address, server backup, or call details in an issue. Revoke exposed credentials through the party host dashboard before requesting help.
