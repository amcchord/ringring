Then open SIP Settings

Keep SIP Registration on, choose TLS for SIP Transport, and keep the sips URI scheme. Under Codec Settings, put PCMU / G.711 μ-law first and prefer DTMF via RTP (RFC2833). Under Advanced Settings, turn Authenticate Server Certificate chain on.

Use the UDP fallback only if TLS will not register

Change Primary SIP Server to {{.SIPPublicHost}}:5060 and SIP Transport to UDP. Keep every username, password, NAT, codec, and DTMF setting the same. One initial 401 is normal and is not a reason to switch transports.

Save and prove it.

Choose Save and Apply, then open Status → Port Status. Registration should say Registered. Grandstream intentionally shows the saved password as blank afterward. Pick up the phone and dial *10 for the echo test.

☎️

Telephone adapter

  1. Plug the telephone into PHONE 1, not the wall.
  2. Open the adapter’s Line 1 or FXS page and use the field translator above.
  3. Use TLS 1.2 with certificate checking when offered; otherwise choose the UDP fallback.
  4. Keep NAT keep-alive or rport on when offered. Do not forward router ports.
📟

VoIP desk phone

  1. Add a SIP account or line and use the field translator above.
  2. Use the extension only as the display number; both SIP user and Auth ID get the generated username.
  3. Choose TLS on port 5061 and a 300–600 second registration expiry.
  4. Save, wait for Registered, then dial *10.
📱

Other softphone app

  1. Add a SIP account manually—do not choose a public phone provider.
  2. Use the generated username for both SIP user and authentication ID.
  3. Choose TLS, keep server-certificate verification on, and enter the settings exactly.
  4. Allow microphone access, then call *10 to test both directions.
RingRing is a private toy phone network. It cannot call regular or emergency phone numbers. Keep another way to call emergency services.
