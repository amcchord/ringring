Telephone adapter

  1. Plug the telephone into PHONE 1, not the wall.
  2. Open the adapter’s Line 1 or FXS page.
  3. Enter the server as proxy/registrar and the username as both User ID and Auth ID.
📟

VoIP desk phone

  1. Add a SIP account or line.
  2. Use the extension as the display number.
  3. Set transport to UDP and registration expiry to 300–600 seconds.
📱

Softphone app

  1. Add an account manually—do not choose a public provider.
  2. Use the server, username, and password exactly as shown.
  3. Allow microphone access, then call *11 to test audio.
